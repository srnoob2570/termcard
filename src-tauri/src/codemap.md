# src-tauri/src/

## Responsibility

Rust backend of Termcard, built as the library crate `termcard_lib` (the `_lib` suffix avoids a lib/bin name collision on Windows). `main.rs` carries no logic, just the `windows_subsystem = "windows"` release attribute and a `main()` that calls `termcard_lib::run()`. Everything else lives in six flat sibling modules:

- `lib.rs` holds the IPC command set: 12 `#[tauri::command]`s (`get_prefs`, `save_prefs`, `run_capture`, `stop_capture`, `export_png`, `export_svg`, `font_css`, `preset_theme`, `default_rules`, `get_home`, `save_png`, `pick_directory`), the `AppState` guard, render-time redaction (`redact_capture_value`), `expand_tilde`/`home_dir`, the save-dialog helper (`rfd_dialog`), and the private `once_store` persistence module. `run()` registers the `opener` and `dialog` plugins, pins the store path in `setup`, manages `AppState`, and lists all commands in `generate_handler![]`.
- `capture.rs` runs a command in a PTY via `portable_pty` and converts raw ANSI output into the IR. Owns the limits `MAX_BUFFER` (5 MB) and `TIMEOUT` (120 s), the result struct `RunOutcome { capture, exit_code, truncated, timed_out }`, and the one real error type, `CaptureError(pub String)`.
- `ir.rs` defines the terminal IR: `Capture { cols, rows, command_line, lines }`, `Line { runs }`, `Run { text, fg, bg, bold, italic, underline }`, and `Color { Indexed(u8), Rgb(u8, u8, u8), Default, DefaultInverted }`. Provides `from_vt100` (per-cell walk with run merging and gap preservation), `Capture::trimmed`, and `str_width` (unicode-width, CJK counts 2 columns).
- `redact.rs` holds `RedactRule { pattern, replacement, enabled, is_default }`, the sequential `Redaction::apply`, `default_rules()` generated from the real environment (home path to `~`, username to `user`, hostname to `localhost`), and a compiled-regex cache.
- `theme.rs` defines `Theme` (preset, backdrop, background, foreground, accent, title, show_traffic_lights, show_shadow, corner_radius, padding, outer_margin, font_size, `card_width: Option<u32>`, prompt_symbol), the `Preset` enum (`MacDark`, `MacLight`, `Minimal`, `Solarized`) whose `Preset::theme()` is the single source of truth for preset values, and `Palette`, which resolves ANSI-256 indices 0–255 to CSS colors.
- `export.rs` renders the card: `layout()` computes logical dimensions, `render_svg` builds the SVG string by hand, `render_png` rasterizes with resvg + fontdb + tiny-skia, `font_css()` serves document-level `@font-face` CSS, and `escape_xml` protects text and quoted attributes. JetBrains Mono metrics are the constants `CH_WIDTH 0.6` (advance width per font-size unit) and `LINE_HEIGHT 1.2`.

## Design

- **Flat modules, one crate.** `termcard_lib` declares `pub mod capture; pub mod export; pub mod ir; pub mod redact; pub mod theme;`. No subdirectories, no trait indirection. All IPC structs carry `#[serde(rename_all = "camelCase")]`; `Theme` additionally uses `#[serde(default)]` so partial themes deserialize with defaults filled in.
- **Single-capture guard.** `AppState { stop: Arc<AtomicBool>, running: tokio::sync::Mutex<bool> }` is Tauri-managed. `run_capture` locks `running`, returns `Err("A capture is already in progress")` if held, and resets it on every exit path, worker panics included, so a crashed capture never locks the UI out. `stop_capture` flips the flag with `Ordering::Relaxed`.
- **Blocking work is isolated.** Capture runs under `tokio::task::spawn_blocking`; rendering under `tauri::async_runtime::spawn_blocking`, because fontdb + resvg + PNG encode are CPU-bound and would freeze the UI thread (the export spinner would never paint).
- **Lazy statics.** `export::FONTS` (four `include_bytes!` TTFs from `src-tauri/fonts/`), `export::FONT_B64` (base64 of the faces, encoded once), and `redact::RE_CACHE` (`LazyLock<Mutex<HashMap<String, Arc<Regex>>>>`, cap `RE_CACHE_CAP = 512`, cleared on overflow, which is safe because it is only a compile cache).
- **Capture pipeline.** `portable_pty::native_pty_system` opens a PTY at 240×80, spawns `$SHELL -c <command>` (fallback `/bin/sh`) with `TERM=xterm-256color` and `COLORTERM=truecolor`, then `vt100::Parser::process` consumes the raw bytes and `ir::from_vt100` converts the final screen: it skips cells without contents and wide-character continuations, preserves gaps of unwritten cells (tabs, cursor moves) as literal spaces styled with the gap cell's attributes, and `merge_run` collapses adjacent runs with identical style. `Capture::trimmed` then removes trailing empty rows and shrinks `cols` to the widest content plus one.
- **Single-renderer principle.** The live preview IS the exported SVG: the frontend injects `export::render_svg`'s string via `dangerouslySetInnerHTML`, and `render_png` rasterizes the exact same `render_svg_inner` output with resvg. Preview and PNG cannot diverge because there is no second renderer.
- **Redaction at render time.** `run_capture` returns the capture UNREDACTED. `redact_capture_value` mutates the serialized `serde_json::Value` in place, rewriting `commandLine` and every `lines[].runs[].text` (guarded with `as_object_mut`, no struct round-trip), so editing rules updates the preview without re-capturing. `export_png` always redacts; `export_svg` honors `show_raw` (`Option<bool>`), the temporary "uncensored" toggle that affects only the preview.
- **Fonts.** `render_svg` emits only `font-family="JetBrains Mono"`, no embedded `@font-face`. The `font_css` command returns the ~1.4 MB base64 CSS for the four faces, which the frontend installs once in a document-level `<style>`; per-render embedding was measured at ~35 ms of the ~70 ms keystroke latency. `render_png` resolves fonts through a fresh `fontdb::Database` and never embeds.
- **Persistence.** Hand-rolled `once_store` module in `lib.rs`: `OnceLock<PathBuf>` store path pinned to `app_config_dir/termcard-store.json`, whole-JSON `load_json`/`save_json`. A corrupt file logs to stderr and starts empty instead of silently wiping settings. Writes are atomic: write `termcard-store.json.tmp`, then rename. Frontend-only fields (like `lang`) ride along opaquely because Rust treats the blob as `serde_json::Value`.
- **Errors.** `Result<_, String>` at the command boundary via `.map_err(|e| e.to_string())`. The one real error type is `CaptureError(pub String)` in `capture.rs` (Display + Error impls); `run_capture` unwraps it with `e.0`, and a `JoinError` from `spawn_blocking` becomes `"export cancelled: {e}"`.

## Flow

1. **Startup.** `run()` initializes plugins, then `setup` calls `once_store::Store::init(app.path().app_config_dir())`, manages `AppState { stop: Arc::new(AtomicBool::new(false)), running: Mutex::new(false) }`, and registers the 12 commands.
2. **Prefs lifecycle.** `get_prefs` calls `Store::load_json()`: missing file returns `json!({})` (first run), corrupt file logs to stderr and returns `json!({})`. The frontend merges the result over `DEFAULT_PREFS` and `defaultRules()`. Every prefs or theme edit persists through `save_prefs` → `Store::save_json`: `create_dir_all`, `to_string_pretty`, write to `*.json.tmp`, atomic rename.
3. **`run_capture(command, cwd)`.** Acquires the `running` mutex (already held → `Err("A capture is already in progress")`), resets the `stop` flag, filters empty `cwd` to `None` and applies `expand_tilde` because the spawned process does no tilde expansion, then dispatches `capture::run_command(&command, cwd, 240, 80, Some(&stop))` on `tokio::task::spawn_blocking`. `running` resets on every exit path before the result maps `CaptureError` to `Err(e.0)` or a JoinError to a string.
4. **Inside the PTY.** `openpty(PtySize { rows: 240, cols: 80, .. })`, spawn via `CommandBuilder` with `TERM`/`COLORTERM` set and optional cwd, then drop the slave. A dedicated reader thread pumps 8 KiB chunks over an `mpsc::channel` (a blocking `read` would hang forever on a silent process), while the main loop polls `recv_timeout(min(remaining, STOP_POLL = 100 ms))`, checking the stop flag, the 120 s deadline, and the `MAX_BUFFER` 5 MB cap (`truncated = true`, then break). Kill order matters: `child.kill()` first (closing the PTY unblocks the reader's pending read), then `reader_handle.join()`, then `child.wait()` for `exit_code`, which is `None` when stop or timeout fired. `vt100::Parser::process(&raw)` → `ir::from_vt100(&parser, command)` → `.trimmed()` produces the `RunOutcome`, returned UNREDACTED to the frontend as `CaptureResult { capture, exitCode, truncated, timedOut }`.
5. **Preview (`export_svg`).** Called on every keystroke or theme/rules change with the raw capture JSON. Inside `tauri::async_runtime::spawn_blocking`: unless `show_raw` is set, `redact_capture_value` applies the rules; `serde_json::from_value::<ir::Capture>`; `export::render_svg(&cap, &theme, &Palette::default(), 1)` returns the SVG string the frontend displays as-is. This string is exactly what the exporter rasterizes.
6. **`export_png(capture, theme, rules, scale)`.** Rejects scale outside `2..=4`, then in `spawn_blocking` always redacts (the export never shows uncensored), deserializes, and calls `export::render_png`: `render_svg_inner` at the requested scale, fonts loaded into `fontdb`, `usvg::Tree::from_str` with default `font_family` of JetBrains Mono, `resvg::render` into a `tiny_skia::Pixmap`, `encode_png`, base64-encode back to the frontend.
7. **`save_png(base64_png, suggested_name)`.** Decodes base64, opens the save dialog through `rfd_dialog` (`app.path().picture_dir()` as start dir, `blocking_save_file` on the `AppHandle`), treats an empty path as user-cancelled, otherwise `std::fs::write` and return the path.
8. **Supporting commands.** `preset_theme(preset)` resolves `Preset::from_id(preset).theme()` or errors on an unknown id; the frontend replaces its whole theme with the response. `default_rules()` returns environment-derived rules, `get_home()` returns `HOME` (falling back to `USERPROFILE`), and `pick_directory(cwd)` opens a folder picker starting at a valid cwd or `$HOME`, returning `""` on cancel.

## Integration

- **`ir.rs` is the contract.** `Capture`/`Line`/`Run`/`Color` are produced by `capture.rs` (`from_vt100` + `trimmed`) and consumed everywhere: `redact.rs` rules apply to run text and the command line, `theme.rs` colors resolve against `Theme`/`Palette`, `export.rs` measures lines with `str_width` and maps all four `Color` variants in `resolve_color` (`Indexed` → palette, `Rgb` → hex, `Default` → theme foreground, `DefaultInverted` → theme background). `Color::Default` exists only for round-trip deserialization of captures saved by older versions; `from_vt100` serializes a default foreground as `None`. Changes here ripple through capture, redact, theme, export, and `api.ts`.
- **`theme.rs::Preset::theme()` is the single source of truth** for the four presets (`mac-dark`, `mac-light`, `minimal`, `solarized`), served over the `preset_theme` command; the frontend swaps its entire theme on preset change. `App.tsx::PRESET_LABELS` holds display labels only. Known duplication to keep in sync: `Theme::default` in theme.rs mirrors `DEFAULT_PREFS` in `src/api.ts`.
- **`redact.rs` regex cache.** `RE_CACHE` avoids recompiling patterns per run; `Redaction::apply` skips disabled or empty patterns, ignores invalid patterns silently (the UI validates separately), doubles `$` in replacements so `$1` never expands as a capture reference, and applies rules in order.
- **`export.rs` constants.** `CH_WIDTH 0.6` and `LINE_HEIGHT 1.2` (JetBrains Mono advance width and line height) drive `layout()` and the per-run width math (`str_width × font_size × CH_WIDTH`). `layout` reserves 44 px chrome with traffic lights or 16 px without, an 8 px shadow gap per side, and floors of 420 px width and 160 px height; `theme.card_width` set to `Some(w)` fixes the window width (text can overflow) while `None` fits the longest line. `Palette::default()` (Catppuccin Mocha) is hardcoded at both export commands in lib.rs; per-preset palettes are not wired yet.
- **`src/api.ts` mirrors everything.** Every IPC struct (`Capture`, `Line`, `Run`, `Color`, `Theme`, `Palette`, `RedactRule`, `CaptureResult`) has a camelCase TS mirror there. Cross-boundary contract: adding an IPC command touches `lib.rs` (command + `generate_handler![]`) and `src/api.ts` (struct mirror + `invoke` wrapper); missing either side fails `tsc` or the runtime invoke.
- **`once_store` is opaque from Rust.** The whole JSON blob round-trips as `serde_json::Value`, so frontend-only preferences persist without touching Rust structs. `tauri-plugin-store` was deliberately removed; the Rust-side `tauri-plugin-dialog` crate stays because Rust opens the dialogs itself via `AppHandle`.

## Tests

- Inline `#[cfg(test)] mod tests` at each file bottom with `use super::*`, behavioral snake_case names (`svg_escapes_xml`, `disabled_rules_skipped`, `cache_cap_clears_on_overflow`), and in-module helper fixtures (`parse`, `rules`, `sample`, `png_dims`), no fixture files. Counted from source: **38 tests total, capture 6, ir 10, redact 9, theme 7, export 6** (repo notes saying 35/export 3 are stale).
- **capture (6)** are not hermetic: they spawn real shells and depend on `$PATH`, GNU `ls --color=always`, and `/tmp`. `stop_flag_kills_hanging_command` is the slowest and flakiest (a 300 ms flag race against `sleep 30`); `timeout_kills_sleep` exercises the real timeout path by calling `run_command_inner` with a 300 ms explicit deadline instead of waiting the full `TIMEOUT`.
- **ir (10)** cover plain text, style splits (bold), truecolor, 256-index, background, inverse video (`DefaultInverted`), empty rows, command-line carry, tab-gap preservation as literal spaces, and `trimmed` counting wide CJK width.
- **redact (9)** cover home→tilde, user+hostname, disabled rules skipped, invalid patterns ignored, sequential application, literal `$1` replacements, `RE_CACHE` cap behavior under 600 patterns, and compile validity of `default_rules`.
- **theme (7)** cover preset overrides for MacLight/Minimal/Solarized, the ANSI-256 cube and grayscale ramps of `Palette::resolve`, base palette values, and a `Theme` serde round-trip.
- **export (6)** verify layout math (420 px floor wins, manual `card_width` above the floor is exact at 696, manual width beats content, automatic ignores manual), prompt/text/traffic-light presence in the SVG, `escape_xml` resistance to attribute breakout from a hostile theme string, and PNG scale rounding within ±1 px by parsing IHDR dimensions.
